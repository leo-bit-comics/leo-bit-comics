# Leo & Bit's AI Adventure · 乐乐和比特的AI大冒险

A free bilingual comic (English / 简体中文) in 13 episodes. Leo, a 13-year-old in Shanghai, and his
pocket robot Bit explore how computers work, all the way to AI, large language models and agents.

一部免费的中英双语漫画，共13集。上海13岁少年乐乐和他的口袋机器人比特，从计算机的原理一路探索到人工智能、大语言模型和智能体。

**Read it / 在线阅读:** <https://leo-bit-comics.github.io/leo-bit-comics/>
